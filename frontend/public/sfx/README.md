# 🔊 SFX — UI da jornada

Sons curtos de UI (opt-in via toggle de som).

| Arquivo           | Uso                                  |
|-------------------|--------------------------------------|
| `click-hud.mp3`   | Clique genérico no HUD               |
| `level-up.mp3`    | Ao revelar o nível após o quiz       |
| `loot.mp3`        | Ao flipar um card de módulo (Ato 3)  |

**Fontes recomendadas (free/licenciáveis):**
- [freesound.org](https://freesound.org/) (CC0)
- [pixabay.com/sound-effects](https://pixabay.com/sound-effects/)
- [zapsplat.com](https://zapsplat.com/)

Formato: `.mp3` 64-128kbps mono, ≤ 200ms de duração.
