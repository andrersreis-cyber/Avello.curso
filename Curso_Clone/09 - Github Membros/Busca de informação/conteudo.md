# Busca de informação

**Descrição:**
Fluxo para busca de informação sobre uma empresa (surface web e dark web), o objetivo é o monitoramento da minha empresa. Sabe se o nome da empresa está sendo mencionado em algum site na internet, se está sendo mencionado na darkweb, verificar publicações de redes sociais a fim de evitar fraudes com o nome da minha empresa(s), verificar se há dados sendo vendidos na dark web, etc. Gerar um relatório e enviar por email.
